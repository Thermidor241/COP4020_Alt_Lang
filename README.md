# COP4020_Alt_Lang

This project was developed using Java SE 8.01.
The main reason I chose this ls due to how similar it is with C++ due to it being another Object Oriented language. Another reason I chose it is due to the vast arrays of libraries and built in functions that I am able to work with. This language supports the use of classes and encapsulation. In terms of file handling, this language has many built in classes that support the use of file reading and ingestion. In fact, the main library I used to work on this assignment is OpenCSV.

Similar to C++, Java supports the use of conditional statements, assignment statements, and loops. Java handles subprograms such as functions and methods by keeping them in classes. This language also supports method overloading. For exception handling, Java uses specific words like try, catch, finally, and throw to deal with errors that might happen while a program is running. These words help in controlling what happens when something unexpected occurs, like when a piece of code goes wrong. The main issue I had was that I wasn't taking this into consideration. Once I caught an IOException, my program started working.

The library .jars I had installed for this program are OpenCSV and Apache Commons
